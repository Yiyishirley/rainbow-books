# Rainbow Books

Website prototype for Rainbow Books, an independent Victorian bookseller (ISYS1051 Digital Business Design and Innovation, RMIT University).

Live site: https://yiyishirley.github.io/rainbow-books/

All buttons and forms work as a demonstration only; no orders, payments or bookings are processed.
